## [1.0.0] — 2026-10-21

### Added
- `shaping` skill: grill-style interview through shaping stages 0–4, playback with an explicit assumptions list, a language choice before writing, and a paste-ready pitch (Problem, Appetite, Solution, Rabbit holes, No-gos), or a not-ready note when something is still open.
- `shapeup-sketch` skill: breadboards and fat marker sketches generated from a JSON spec into `.excalidraw` and PNG files, with a `doctor` check and a fallback to editable files when the renderer is missing.
- `.shaping.json` configuration: cycle length, languages, output folder, pitch destination and shaper name.
- Bundled shaping guide, flowchart and example pitch.
